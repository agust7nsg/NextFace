# NextFace

React, TypeScript and Capacitor app, backed by Supabase.

## Development

1. Install dependencies with `npm ci`.
2. Copy `.env.example` to `.env` and configure the Supabase URL and public anon key.
3. Run `npm run dev`.

Build with `npm run build`. Sync Android with `npm run cap:sync`.

The Home screen includes a scoped UI/UX design refresh. Other screens retain their original design.

Environment files and generated build output are excluded from version control.
